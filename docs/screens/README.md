# 吉祥物出現的畫面

所有放了吉祥物的畫面截圖。由 `tools/capture_mascot_screens.js` 產生（用法在檔案開頭註解），
改了畫面或換了圖之後重跑即可更新。圖片來源與用途清單見 `assets/README.md`。

| 檔案 | 畫面 | 吉祥物 |
