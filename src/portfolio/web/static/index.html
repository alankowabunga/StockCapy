入手價對照

點一列展開估值模型明細與價格位置。已到價的列以綠色標示。

持倉

成本基礎用移動平均法，與券商報稅用的 FIFO 不同。

淨值走勢

來自每日快照，快照不足時無法繪製。

風險指標

以目前持倉回溯計算，非歷史實際交易績效。

股利

已領金額依券商紀錄；預估依當前配息率推算。

價格監控

同一檔同一天只通知一次；改了目標價會自動重新武裝。

新增監控

入手價與出場價至少填一個，不必持有該檔。

立即檢查

比對現價與提醒價，到價就發通知。

智慧提醒

技術指標 + 均價規則觸發的現況描述，不是買賣建議。門檻由你設定，上線前先回測。

通知對象

持股與監控清單預設都會推播。關掉的股票仍會列在上方，只是不推播；也可以加入沒持有的股票。

立即檢查

重新評估並推播新觸發（同樣條件要再走 5% 或滿 7 天才重送）。

門檻

留空的欄位沿用通用預設。代號填 * 改通用預設。

觸發歷史

過去實際觸發並通知過的智慧提醒。

手動持倉

估值假設

target P/E 是最關鍵的假設；先看入手價分頁裡的實際 P/E 再設。報酬率與成長率用小數（0.09 = 9%）。

所有估值為機械模型輸出，非投資建議。
